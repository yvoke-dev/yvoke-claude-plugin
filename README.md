# Yvoke for Claude

A Claude plugin that brings Yvoke Desktop's capabilities into Claude: playbook-scoped, cited answers from the
Yvoke knowledge base, 👍/👎 feedback to yvoke-web, and multi-agent investigations.

- **Claude Code** (the Claude Desktop app's **Code** tab and the terminal): full feature set, through a mod.
- **Cowork** and **Chat**: playbooks and the knowledge-base connector, with fewer guarantees.

**Status:** planning. Nothing is implemented yet. The work and its progress are tracked in [PLAN.md](PLAN.md).
